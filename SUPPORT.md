# Support

**Maintainer:** Vinay Shankar  
**Email:** vinay@tfaworld.org  
**Website:** https://tfaworld.org/

For software questions, bugs, or documentation feedback, use the repository issue tracker when the information can be public.

For questions that should not be placed in a public issue, contact **vinay@tfaworld.org**.

When requesting support, provide:

- application version;
- MATLAB release;
- Windows version;
- complete error message;
- relevant configuration settings;
- expected sensor/stream layout;
- observed sample-rate sequence where available.

Do not send identifiable participant data unless you have an appropriate secure, authorized mechanism and a legitimate need to do so.
