## 1.1.0 — 2026-09-07

- Added public contact email `vinay@tfaworld.org` throughout source, GUI, configurations, QC reports, conversion metadata, citation metadata, and documentation.
- Expanded public documentation with installation requirements, first-run workflow, configuration reference, QC interpretation, output formats, troubleshooting, FAQ, and multiple acquisition/use-case scenarios.
- Added `CONTRIBUTING.md` and `SUPPORT.md`.
- Clarified that sampling-rate QC validates signal type/order consistency but does not independently establish anatomical sensor identity.
- Clarified Windows/Delsys `HPF.dll` requirement and that Signal Processing Toolbox is not required by the current workflow.

## 1.0.0 — 2026-09-07

- Initial public GitHub-ready release.
- Generic HPF file discovery with filename and folder filtering.
- Configurable EMG/ACC sample-rate QC.
- Up to 16 ordered sensor definitions.
- Reusable MATLAB configuration profiles.
- Stream-level and deep QC.
- Separate EMG and ACC exports.
- Never-overwrite safeguards.
- Conversion provenance metadata.
- Author and website attribution throughout the application and generated metadata.
